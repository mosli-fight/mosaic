# Icon libraries — licensing note

The icons in `icons.ts` (tech, databases, DevOps, AWS, Azure, GCP and Kubernetes) are **original geometric drawings made for Mosaic**. None of them is vendor artwork.

## What was drawn, and why

AWS, Azure and Google Cloud icons are proprietary vendor trademarks. Their official icon sets ship under terms that do not allow copying the artwork into another product, so the catalogue does not use them. Instead:

- every glyph is a rounded square tile with a white letter or short mark (`JS`, `PG`, `S3`, `EC2`, …);
- cloud-provider glyphs add a simple three-circle cloud silhouette above the mark;
- Kubernetes glyphs add a plain hexagon around the mark;
- colours are the vendors' widely-known brand hues, used only to make the tile recognisable. Colour alone is not the artwork.

The result is deliberately schematic: it reads as "this node is an S3 bucket" on a diagram without reproducing a trademarked logo.

The vendor names (`AWS`, `Azure`, `GCP`, `Kubernetes`, …) appear only as labels — the names of the things the tiles stand for — which is nominative use. The drawings themselves are Mosaic's own.

## If artwork is ever swapped in

Any future icon that is not drawn here must be CC0, MIT (or another permissive licence that allows redistribution and modification), and its source and licence must be recorded next to the entry. Do not paste vendor SVGs from documentation sites.
